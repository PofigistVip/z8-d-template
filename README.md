# Z8 D Template

Шаблон приложения Z8 на D, основанный на `z8-template`. BL-исходники моделей,
представлений и настройки доступа, а также клиентские JavaScript, CSS и HTML
сохранены из исходного шаблона. Компилятор и runtime подключаются из `z8-d`.

## Сборка

Нужны Python 3, DMD, DUB, C-компилятор, клиентские библиотеки PostgreSQL,
собранный `z8d`, исходные деревья `z8-d` и `org.zenframework.z8`. Последнее
пока используется для стандартной BL-библиотеки и ресурсов веб-клиента.

В PowerShell из каталога шаблона:

```powershell
python build.py --z8-d C:/path/to/z8-d --original-z8 C:/path/to/org.zenframework.z8 --postgres-bin 'C:/Program Files/PostgreSQL/15/bin'
```

Вместо первых двух параметров можно установить `Z8_D_ROOT` и `Z8_ORIGINAL_ROOT`.
Каталог PostgreSQL определяется через `--postgres-bin`, `Z8_PG_BIN` или
`pg_config`. Сборка создаёт `build/z8-template.exe` (в Unix — `build/z8-template`)
и `build/public`; при повторной сборке каталог `build/public` пересоздаётся.
В Windows каталог `bin` PostgreSQL должен находиться в `PATH` при запуске.

## Запуск

Заранее создайте базу и схему, в которой пользователь подключения может создавать
таблицы. В каталоге проекта выполните:

```powershell
$connection = 'host=127.0.0.1 dbname=z8 user=z8 password=z8'
./build/z8-template.exe $connection public --initialize
# Установите пароль Admin в SystemUsers, как описано ниже.
./build/z8-template.exe $connection public
```

При `--initialize` запускается генератор схемы приложения, в том числе его BL-хуки
настройки прав и меню. Для администратора задайте пароль в `SystemUsers`: поле
`Password` содержит MD5 пароля в представлении, ожидаемом Z8. Например, для
локальной базы можно выполнить `UPDATE "SystemUsers" SET "Password" = md5('пароль')
WHERE "RecordId" = '00000000-0000-0000-0000-000000000002'`. Используйте собственные
учётные данные.

По умолчанию сервер слушает `127.0.0.1:9080`, а клиент находится в `build/public`.
Доступны обычная страница `index.html` и страница отладки `debug.html`.
Адрес можно изменить через `--listen 127.0.0.1:9090`, путь к клиенту — через
`--public-dir`, файл настроек — через `--config`. Если `--config` не задан, при
наличии загружается `server.properties` из текущего каталога. Для остановки
нажмите Enter в консоли сервера.

## Интеграционная проверка

После сборки тест создаёт временный экземпляр PostgreSQL, запускает сервер и
проверяет вход, меню, документы, историю, фильтр и загрузку файла:

```powershell
python tests/e2e.py --z8-d C:/path/to/z8-d --postgres-bin 'C:/Program Files/PostgreSQL/15/bin'
```

Реализация `z8-d` и совместимость всех функций исходного шаблона ещё развиваются;
успешная сборка сама по себе не подтверждает полную эквивалентность.
# Экспорт таблиц

Команда клиента «Microsoft Excel (*.xls)» создаёт файл Excel в формате XLSX
с расширением `.xlsx`. Экспорт учитывает фильтры и права текущего пользователя.
Экспорт в PDF пока не реализован.
